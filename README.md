# gps24.es

Сайт GPS24 — GPS-навигация и видеорегистраторы, Бенидорм / Comunidad Valenciana.
Astro 5 (static) + ванильный CSS на дизайн-токенах + минимум JS. Три языка:
ES (канон, `/`), EN (`/en/`), RU (`/ru/`).

Проектная документация (ТЗ, канон дизайна, оперативное состояние) — в приватном
репо `amllpost-byte/gps24`.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm install` | зависимости |
| `npm run dev` | дев-сервер на `localhost:4321` |
| `npm run build` | проверка паритета i18n-ключей + сборка в `dist/` |
| `npm run preview` | локальный просмотр собранного `dist/` |
| `npm run check:i18n` | наборы ключей `ui.es/en/ru.json` обязаны совпадать |

## Структура

- `site.config.ts` — единственный источник бизнес-данных (телефон, сроки, trust-бар).
- `src/styles/tokens.css` — все дизайн-токены (light + dark); компоненты используют только `var(--…)`.
- `src/content/` — коллекции: `products/` (1 файл = 1 SKU, три локали в frontmatter), `services/`, `faq/`.
- `src/i18n/` — словари UI + карта слагов между языками (`routeMap`).
- `src/components/pages/` — шаблоны страниц; файлы в `src/pages/` — тонкие локальные обёртки.

Правило контента: ТТХ — только из проверенных источников (поле `source`
обязательно в схеме); нет источника — строки нет.

## Деплой

GitHub Pages через `.github/workflows/deploy.yml`: build на каждый PR в `main`,
деплой — только с `main`. Кастомный домен задаёт `public/CNAME`; DNS живёт в
DonDominio и из этого репо не трогается.
